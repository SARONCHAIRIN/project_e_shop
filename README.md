# ✨ Overview

**E Shop** is a modern full-featured e-commerce marketplace application built with **Flutter**.

The application provides a complete shopping experience including:

- 🔐 User authentication
- 🏠 Product browsing
- 📂 Product categories
- 🔎 Product search
- 🛍️ Product details
- 🛒 Shopping cart
- 📍 Address management
- 💳 Checkout
- 🇰🇭 Bakong QR payment
- 📦 Order management
- 📋 Order history
- 👤 Profile management
- 🌍 Khmer & English localization

The project follows a scalable architecture with REST API integration and a modern Flutter UI.

# 🚀 Features

<tr>

<td width="50%" valign="top">

### 🔐 Authentication
- JWT-based authentication
- Secure token persistence
- Seamless login & logout flow
- Session management & guards
- Protected API requests

### 🛍️ Marketplace
- Rich product browsing interface
- Categorized item exploration
- Detailed view specifications
- High-resolution product images
- Real-time inventory tracking
- Instant product search

### 🛒 Shopping Cart
- Dynamic item management
- Add/remove products seamlessly
- Real-time quantity adjustments
- Instant subtotal calculations
- Frictionless checkout pathway

### 📍 Address Management
- Location and address additions
- Update and delete capabilities
- Delivery address selection
- Map-based location support

</td>

<td width="50%" valign="top">

### 💳 Payment Systems
- **Cash on Delivery (COD)** checkout support
- **🇰🇭 Bakong QR** dynamic generator
- Live payment verification & status
- Seamless success & failure handling

### 📦 Order Operations
- Create and track orders
- Comprehensive order summaries
- Historical transaction logs
- Live order & payment statuses
- Interactive order success feedback

### 🌍 Localization
- Full bilingual switching:
    - 🇬🇧 English
    - 🇰🇭 Khmer
- Powered by `easy_localization`

### 🎨 UI / UX Polish
- Shimmer loading skeletons
- Engaging Lottie animations
- Efficient image caching
- Fully responsive design layouts

</td>
