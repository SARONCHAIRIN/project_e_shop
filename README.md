- JWT authentication
- Secure token storage
- Login & logout
- User session management
- Protected API requests

---

- Product browsing
- Product categories
- Product details
- Product images
- Inventory information
- Product search

---

## 🛒 Shopping Cart

- Add products
- Remove products
- Update quantities
- Cart total calculation
- Checkout flow

---

## 📍 Address Management

- Add address
- Update address
- Delete address
- Select delivery address
- Map-based location

</td>

### Cash on Delivery

Simple checkout using COD.

- Generate Bakong QR
- Display payment QR
- Payment verification
- Transaction status
- Payment success / failure handling

---

- Create orders
- Order details
- Order history
- Order status
- Payment status
- Order success screen

---

- 🇰🇭 Khmer

Powered by:

`easy_localization`

- Lottie animations
- Image caching
- Responsive layouts
- Modern navigation

- Clean reusable widgets
